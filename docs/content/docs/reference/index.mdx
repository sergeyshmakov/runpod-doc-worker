This reference covers the public functions intended for worker composition in v0.1.0. The package is pre-release, so pin a tag and review changes before upgrading.

## Root package

```python
from runpod_doc_worker import WorkerConfig, active, configure, __version__
```

| Name | Purpose |
| --- | --- |
| `WorkerConfig` | Immutable worker-owned configuration |
| `configure(config)` | Install process-wide configuration |
| `active()` | Return the active configuration |
| `__version__` | Installed package version |

`DEFAULT_VOLUME_ROOTS` is exported from `runpod_doc_worker.config`.

## Artifact contract

From `runpod_doc_worker.contract.artifacts`:

| Name | Purpose |
| --- | --- |
| `Artifact(key, patterns, kind, default, required)` | Declare one response field |
| `ArtifactError` | Raised when a `required` artifact is absent or unreadable |
| `validate(manifest)` | Validate the manifest and return a tuple |
| `resolve(manifest, output_dir, basename, keys=None, report=None)` | Read selected artifacts |
| `keys(manifest)` | List declared keys in order |

Valid kinds are `text`, `json`, and `b64map`. `required` applies to `text` and `json` only.

From `runpod_doc_worker.contract.degraded`:

| Name | Purpose |
| --- | --- |
| `Report()` | Collect what packaging had to drop or substitute across one or more entries |
| `Report.note(reason=..., file=..., artifact=None, error_type=None)` | Record one loss and log it |
| `Report.entry()` | The `degraded` value, or `None` when nothing was lost |
| `Report.count` | Everything noted, including items the report does not list |
| `MESSAGE` | The stdout warning every loss is logged under. Stable: alert rules and log mirrors match it |
| `ENTRY_KEY`, `MAX_ITEMS`, `VALID_REASONS` | The response key, the item cap, the reason vocabulary |

Reasons are `unreadable`, `unresolvable`, `outside_output_dir`, and `unsafe_name`.

## Result packaging

From `runpod_doc_worker.transport.package`:

| Function | Purpose |
| --- | --- |
| `package_results_entry(..., report=None)` | Build one transport-specific result dictionary. Pass a job-wide `Report`; the returned `degraded` field remains entry-local |
| `package_inline(...)` | Resolve selected manifest values |
| `package_tarball(output_dir, archive_format="tar.gz", report=None)` | Return a base64 archive |

Valid transports are `inline`, `tarball_b64`, and `s3`. Valid documented archive formats are `tar.gz` and `zip`.

### Scoping the local-fetch bypass

`<PREFIX>_ALLOW_LOCAL_FETCH` is an **operator's** exemption: it lets the worker
fetch documents from a private mirror. It is scoped to the whole worker, so without
care it also exempts every URL a *caller* supplies in a job payload — and a caller
naming `169.254.169.254` for a model-server field would then reach cloud metadata
from inside the worker's network.

Pass `allow_local=False` to `check_target`, `resolve_checked` or
`resolve_checked_host` for any URL that came from a job payload. `None`, the
default, consults the operator's setting as before.

```python
# an operator's document mirror keeps its exemption
net.check_target(file_url, field="file_url")

# a caller-supplied target does not get it
net.check_target(server_url, field="server_url", allow_local=False)
```

## Response size

`runpod_doc_worker.transport.response_size` — refusing a response the gateway would
discard rather than have it dropped silently. Off unless a worker opts in; see
[Packaging → the response-size cap](/docs/guides/packaging/#the-response-size-cap).

| Name | Kind | Notes |
|---|---|---|
| `ENFORCE_RESPONSE_CAP` | `bool` | `False` by default. Set `True` to refuse an undeliverable response |
| `MAX_RESPONSE_MB` | `int` | `20`, the `/runsync` ceiling. Raise to disable the refusal |
| `BULKY_ARTIFACT` | `str \| None` | The heaviest optional output, named in the refusal |
| `ResponseTooLargeError` | exception | Raised by `package_results_entry` when enforcement is on |
| `ResponseBudget` | class | One per response, so several entries are measured together |
| `exceeds_gateway_cap` | function | The predicate, for a worker deciding before it packages |
| `measure_entry_bytes` | function | Serialised size of an entry, escaping included |
| `oversized_response_error` | function | The message, if a worker wants to report it itself |
| `refuse_if_undeliverable` | function | Measure, check and raise in one call |

The client half has its counterpart, `runpod_doc_client.describe_dropped_response`,
for explaining a response that *was* dropped — against a worker without the guard,
or on `/run` where the cap is half as high.

## Environment variables

`<PREFIX>` is the `env_prefix` from `WorkerConfig`.

| Variable | Default | Used by |
| --- | --- | --- |
| `<PREFIX>_VOLUME_ROOTS` | Configured roots | Volume input containment |
| `<PREFIX>_ALLOW_LOCAL_FETCH` | Disabled | URL target policy |
| `LOG_FORMAT` | `json` | Log rendering; set `text` for local output |
| `LOG_LEVEL` | `info` | Set `debug` to enable debug records |
| `BUCKET_ENDPOINT_URL` | None | Required S3 endpoint |
| `BUCKET_NAME` | None | Required S3 bucket |
| `BUCKET_ACCESS_KEY_ID` | None | Required S3 access key |
| `BUCKET_SECRET_ACCESS_KEY` | None | Required S3 secret |
| `BUCKET_REGION` | None | Optional S3 region |
| `BUCKET_PREFIX` | Empty | Optional object-key prefix |
| `BUCKET_PRESIGN_TTL_SECONDS` | `3600` | S3 URL lifetime, clamped to 60 through 604800 |
| `HF_HUB_CACHE` | Library default | Preferred Hugging Face Hub cache override |
| `HUGGINGFACE_HUB_CACHE` | Library default | Legacy Hub cache override |
| `HF_HOME` | Library default | Hugging Face home used to derive the Hub cache |
| `XDG_CACHE_HOME` | Platform default | Cache root when Hugging Face overrides are absent |

Proxy environment variables are honored by URL fetching. A proxy is responsible for the destination policy of hostnames it resolves.
